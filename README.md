# YT Fast — application Android

Versions publiées de l'application **YT Fast** (téléchargement de vidéos YouTube, lecteur, torrents via AllDebrid).

Ce dépôt ne contient que les fichiers d'installation : l'application vérifie ici s'il existe une nouvelle version
et propose de l'installer.

- Dernière version : onglet **Releases** → fichier `.apk`.
- Installation manuelle : téléchargez l'APK sur l'appareil et ouvrez-le.
